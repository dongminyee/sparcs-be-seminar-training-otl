# 08 · 리뷰 하트와 트랜잭션

다른 사용자의 리뷰에 하트를 누르거나 취소합니다. [리뷰 컨트롤러](../../apps/api/src/reviews/presentation/reviews.controller.ts)의 하트 스텁에서 시작하세요.

| 요청                                                      | 성공  |
| --------------------------------------------------------- | ----- |
| `POST /api/lectures/:lectureId/reviews/:reviewId/heart`   | `204` |
| `DELETE /api/lectures/:lectureId/reviews/:reviewId/heart` | `204` |

## 구현 범위

- `review_heart`에 리뷰·사용자 복합 키를 두고, `review`에 기본값 0인 `heart_count`를 추가합니다. 기존 리뷰를 보존하는 Prisma 마이그레이션을 작성합니다.
- 등록·취소는 JWT로 보호합니다. 자신의 리뷰에 하트를 누르거나 취소하려고 하면 `403`을 반환합니다.
- Service의 `@Transactional()` 트랜잭션에서 하트 행을 추가하거나 제거하고 카운트를 함께 갱신합니다. 행이 실제로 바뀐 경우에만 카운트를 증감합니다.
- 리뷰 조회에 `heartCount`와 `heartedByMe`를 반환해 Next에서 하트 수와 로그인한 사용자의 선택 상태를 표시합니다.
- 리뷰를 삭제하면 그 리뷰의 하트 행도 함께 제거합니다.

## 완료 확인

- `student`로 로그인해 자료구조를 펼치고 `student2`의 예시 리뷰에 하트를 누릅니다. 숫자가 1 증가하고 새로 조회해도 선택 상태가 유지됩니다.
- 등록을 연속으로 요청해도 한 번만 증가합니다. 취소를 반복해도 한 번만 감소합니다.
- 동시에 등록 요청을 보내거나 카운트 갱신이 실패하는 경우를 확인합니다. 커밋된 `heart_count`는 그 리뷰의 실제 하트 행 수와 같아야 합니다.
