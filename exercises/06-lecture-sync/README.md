# 06 · Cron 강의 동기화

보조 NestJS의 강의 피드를 주기적으로 읽고, 새 개설강의를 반영한 뒤 실습 계정 시간표에 자동으로 담습니다. [보조 서버의 강의 데이터](../../apps/source/src/lecture-feed.ts)를 확인하세요.

## 구현 범위

- 스케줄러, 동기화 Service와 Repository를 `LecturesModule`에 등록합니다.
- Scheduler는 `@Cron("*/10 * * * * *")`로 10초마다 동기화 Service를 호출합니다.
- `GET http://127.0.0.1:3002/api/lectures`의 응답을 검증하고, 보조 서버가 부여한 강의 ID를 기준으로 강의와 수업시간을 동기화합니다.
- 처음 가져온 강의는 04단계의 `TimetableService.addTimetableLecture`를 통해 실습 계정에 담습니다.
- 시간표 충돌은 로그에 기록하고 다음 강의를 처리합니다. 충돌한 강의도 개설강의에는 남아야 합니다.
- 반복 동기화는 사용자가 뺀 강의를 다시 담거나, 05단계에서 삭제된 강의를 다시 공개하지 않아야 합니다.

## 완료 확인

빈 실습 DB에서 실행하면 다음을 확인할 수 있습니다.

- `2002` 프로그래밍 언어는 개설강의와 실습 계정 시간표에 모두 나타납니다.
- `2003` 알고리즘 설계와 `2004` 응용확률론은 `2002`와 겹쳐 개설강의에만 남습니다. 로그에 두 건의 자동 담기 건너뜀이 표시됩니다.
- `2002`를 직접 빼고 다음 동기화를 기다려도 시간표에 다시 나타나지 않습니다.
- `2001`은 보조 서버가 기동 후 최소 90초 뒤 삭제를 요청하면 개설강의와 시간표 양쪽에서 사라집니다.
