# 03 · 시간표 모델과 마이그레이션

[Prisma 스키마](../../apps/api/prisma/schema.prisma)에 사용자와 개설강의를 연결하는 시간표 모델을 추가합니다. 한 사용자는 여러 강의를 담을 수 있고, 하나의 강의는 여러 사용자에게 담길 수 있습니다.

## 구현 범위

- `TimetableLecture` 모델에 `userId`, `lectureId`를 두고 양쪽 모델에 외래 키 관계를 연결합니다.
- 사용자·강의 쌍을 복합 기본 키로 만들어 같은 강의를 한 사용자에게 중복으로 담을 수 없게 합니다.
- 강의 외래 키에서 연쇄 삭제를 사용하지 않습니다. 05단계에서 이벤트 핸들러가 시간표 연결 행을 지웁니다.
- 기존 DB에 적용할 Prisma 마이그레이션을 생성하고 스키마 변경과 함께 커밋합니다.

## 완료 확인

```sh
pnpm db:up
pnpm db:migrate --name add_timetable
```

- 생성된 SQL에서 새 테이블의 복합 기본 키와 두 외래 키를 확인합니다.
- 기존 초기 계정과 강의가 보존되고, 다시 실행했을 때 추가로 적용할 마이그레이션이 없어야 합니다.
