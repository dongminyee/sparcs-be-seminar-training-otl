# 05 · 강의 삭제 이벤트

보조 서버의 강의 삭제 요청을 받고, 강의 상태 변경과 시간표 정리를 이벤트로 분리합니다. [강의 컨트롤러](../../apps/api/src/lectures/presentation/lectures.controller.ts)의 삭제 스텁에서 시작하세요.

## 구현 범위

- `DELETE /api/lectures/:id`는 보조 서버가 로컬 실습 Nest에 직접 호출합니다.
- 강의 Service는 `deletedAt`을 설정하고 `LectureDeleteEvent`를 발행합니다. 이벤트 핸들러는 해당 강의가 담긴 모든 사용자의 시간표 연결 행을 제거합니다.
- 강의 상태 변경과 시간표 정리를 `@Transactional()`로 시작한 같은 트랜잭션에서 완료합니다. 핸들러가 실패하면 두 변경을 함께 롤백합니다.
- 이미 삭제한 강의를 다시 요청하면 `204`, 존재하지 않는 강의 ID를 요청하면 `404`를 반환합니다.

## 완료 확인

검증용 DB에서 `1005` 신호 및 시스템을 시간표에 먼저 담고 다음 요청을 실행합니다.

```sh
curl -i -X DELETE http://127.0.0.1:3001/api/lectures/1005
```

- 응답은 `204`입니다. 강의 목록과 시간표에서 사라지고, DB에서도 해당 시간표 연결 행이 제거되어야 합니다.
- 같은 삭제 요청을 다시 보내도 `204`입니다.
- 보조 서버가 삭제하는 `2001`의 전체 흐름은 06단계에서 확인합니다.
